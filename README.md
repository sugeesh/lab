# lab

A personal playground for coding experiments, practice and trying out new tools and
workflows. Things here are works in progress, some polished, some first attempts kept
for comparison.

## What's inside

- **`leetcode/`** – Python solutions to coding problems, mostly data-structure design
  questions, sometimes with both a first attempt and an optimized version.
- **`spec-driven-development/`** – Experiments with spec-driven development, where a
  project is built from a written spec using AI coding agents.
